# Electech Lab - Programming Better Futures

Welcome to the Electech Lab website repository! This is the official website for Electech Lab, a coding company dedicated to delivering engaging coding clubs for Key Stage 2 children in primary schools.

## 🎯 About Electech Lab

At Electech Lab, we empower young learners with coding skills through three exciting courses:

- **Electronics** - Discover the fundamentals of electronics through hands-on projects
- **Games Development** - Create your own games from scratch
- **Robotics** - Build and program robots to complete challenges

## 📁 Website Structure

- `index.html` - Main website page
- `styles.css` - Styling and responsive design

## 🚀 Deployment

This website is hosted on GitHub Pages. To enable:

1. Go to repository **Settings** → **Pages**
2. Select `main` branch as source
3. Your site will be live at: `https://NateTabi.github.io/electech-lab/`
